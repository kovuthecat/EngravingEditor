## T-136 — PWA : manifest + plein écran + safe-area

### Objectif
Rendre l'app installable sur l'écran d'accueil iPad et l'afficher en plein écran (récupère ~70 px, évite
le swipe-back accidentel), en respectant les zones sûres.

### Décision clé
`DECISIONS.md §D-012` pt 7. `apple-mobile-web-app-capable` + manifest ; `viewport-fit=cover` +
`env(safe-area-inset-*)` sur header et barres flottantes. App **sans build** : le manifest est un fichier
statique, aucune dépendance (cohérent D-002).

### Lire / Modifier
- Modifier : `index.html` (`<head>` + `<body>`), `src/style.css`, **nouveau** `manifest.webmanifest`.

### Étapes
1. Créer `manifest.webmanifest` : `name`, `short_name`, `display:"standalone"`, `background_color`,
   `theme_color` (cohérents avec `#0f1115`/`#161922`), `start_url:"."`, une ou deux `icons` (data-URI SVG
   ou PNG inline acceptables pour rester sans asset externe ; sinon icône minimale).
2. `<head>` : `<link rel="manifest" href="manifest.webmanifest">` ; metas Apple :
   `apple-mobile-web-app-capable=yes`, `apple-mobile-web-app-status-bar-style=black-translucent`,
   `apple-mobile-web-app-title`. Compléter le viewport : `viewport-fit=cover`.
3. **CSS safe-area** : `header` et les barres flottantes (`#edit-toolbar`, mini-barres, badge) prennent
   `padding`/`inset` avec `env(safe-area-inset-top/bottom/left/right)` pour ne pas passer sous l'encoche/
   les coins arrondis en standalone paysage.
4. Vérifier que l'app reste ouvrable en `file://` et via URL statique (le manifest est ignoré sans
   incidence en `file://`).

### Validation
- Auto : `node test/run.js` → vert ; ouverture sans erreur console.
- Humain : sur iPad, « Ajouter à l'écran d'accueil » → l'app se lance en plein écran, header/barres non
  masqués par les zones sûres en paysage. → `VALIDATION.md` (P9 · S10).

### Si bloqué
Si aucune icône inline satisfaisante n'est disponible → livrer le manifest avec une icône SVG minimale
et signaler qu'une vraie icône reste à fournir (non bloquant).

### Commit
`feat(pwa): manifest + plein écran iPad + safe-area [P9/T-136]`
