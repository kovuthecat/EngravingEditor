## T-126 — Cibles tactiles CSS 44 px

### Objectif
Porter toutes les cibles tactiles à ≥ 44 px sans grossir le visuel là où la densité compte, et
conditionner l'aide desktop au pointeur fin.

### Décision clé
`DECISIONS.md §D-012` pt 1 : variable `--tap: 44px` ; hit élargi par `::after` transparent 44×44 pour
`×`/`.zone-toggle` (visuel inchangé, zéro impact layout) ; sliders pouce ~28 px + piste hit 44 px.
Pt 7 : `.hint` masquée sous `(pointer: coarse)`.

### Lire / Modifier
- Modifier : `src/style.css` uniquement.

### Étapes
1. Déclarer `:root { --tap: 44px; }` en tête.
2. `.btn` (l.47-48) : `min-height: var(--tap)` ; `.btn.sm` : garder la police 12px mais `min-height:
   var(--tap)` (ou hit `::after` si l'agrandissement casse une grille — préférer `min-height`).
   `#btn-undo` (l.9) : `min-height: var(--tap)`.
3. `.zone-toggle` (l.73) et `.lib-del` (l.94-99) : garder la taille visuelle actuelle, ajouter un
   `::after { content:""; position:absolute; inset:50% auto auto 50%; width:var(--tap);
   height:var(--tap); transform:translate(-50%,-50%); }` (le parent doit être `position:relative` —
   `.lib-item`/`.zone-row` le sont ou à rendre tel). Vérifier que le `::after` ne recouvre pas les
   éléments voisins au point de voler leurs taps (garder la densité raisonnable).
4. Sliders (`#brush-size`, `#calli-angle`, `#pressure-min-width`, `#export-dpi` et tout
   `input[type=range]`) : styliser `::-webkit-slider-thumb`/`::-moz-range-thumb` à ~28 px et augmenter
   la hauteur de hit de la piste (padding vertical ou `height`) vers 44 px.
5. Conditionner l'aide desktop : sous `@media (pointer: coarse) { .hint { display:none; } }`
   (compléter la règle 700px existante l.15-20 plutôt que la remplacer).
6. Vérifier qu'à largeur desktop (souris) rien n'est cassé (les cibles peuvent grossir, c'est acceptable).

### Validation
- Auto (bloque le commit) : `node test/run.js` → vert (garde-fou, aucune géométrie touchée).
- Humain (visuel/UX, non bloquant) : sur iPad, mesurer au doigt Pinceau/Gomme/×/toggle/sliders (aucune
  cible < 44 px, pas de tap volé entre voisins), header lisible sans `.hint`. → `VALIDATION.md` (P9 · S1).

### Si bloqué
Si un `::after` 44×44 recouvre systématiquement la cible voisine dans une grille dense (`library-grid`
2 colonnes) au point de rendre le tap ambigu → STOP, signale (on arbitrera densité vs hit).
