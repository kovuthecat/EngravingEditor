## T-137 — Logger twist / inclinaison / pression tangentielle

### Objectif
Étendre la page de sonde pour mesurer sur l'iPad réel les capacités Pencil Pro nécessaires au Lot E,
afin de trancher le go/no-go (T-138) avant tout code applicatif.

### Décision clé
`DECISIONS.md §D-012` pt 8 : le support Safari de `twist` (barrel roll Pencil Pro) est **non confirmé**
→ la sonde doit le mesurer. On logge les champs `PointerEvent` : `twist`, `altitudeAngle`,
`azimuthAngle`, `tangentialPressure` (+ rappeler `pressure` déjà présent).

### Lire / Modifier
- Modifier : `test/pencil-probe.html` uniquement.

### Étapes
1. Dans le handler `pointermove`/`pointerdown` existant, lire et afficher (mêmes champs live que
   `pressure`) : `e.twist`, `e.altitudeAngle`, `e.azimuthAngle`, `e.tangentialPressure`.
2. Afficher pour chacun : valeur courante + min/max observés sur la session (pour voir si la valeur
   **varie réellement** ou reste figée à 0 / à une constante — un `twist` toujours 0 = non exposé).
3. Ajouter une ligne de verdict auto simple par champ : « varie » (min≠max observés) vs « figé » —
   suffisant pour le go/no-go humain.
4. Garder la page autonome (aucun import de l'app, ouvrable en `file://` et via URL).
