## T-140 — 4ᵉ mode de trait « ombrage » (inclinaison)

### Objectif
Ajouter un mode où la largeur du trait augmente quand le stylet se couche (inclinaison faible), à la
manière d'un crayon d'ombrage — en réutilisant la chaîne `variableStroke` existante.

### Décision clé
`DECISIONS.md §D-012` pt 8. `altitudeAngle` (≈ π/2 = vertical, → 0 = couché). Mapping : radius ∝
fonction décroissante de `altitudeAngle` (couché = large), bornée par `edit.sizeMm`. Même point d'entrée
que le mode Pression (`applyStroke` construit un tableau de radii et appelle `ML.variableStroke`). Ne
s'active qu'au Pencil (`pointerType==="pen"`) ; fallback largeur constante sinon.

### Lire / Modifier
- Modifier : `src/app.js`, `index.html` (bouton du 4ᵉ mode), `src/style.css` si besoin.
- **Ne pas** modifier `geometry.js` / `test/run.js`.

### Étapes
1. Capturer l'inclinaison par point comme la pression : ajouter `edit.altitudes` (rempli dans
   `startStroke`/`moveStroke`/`endStroke` à côté de `edit.pressures`, via `e.altitudeAngle`).
2. Ajouter le mode `strokeMode === "shade"` : dans `applyStroke`, brancher une branche analogue à
   `pressure` qui calcule `radii` depuis `edit.altitudes` (mapping altitude→largeur, borné min/max) et
   appelle `ML.variableStroke(localPts, radii)`. Gomme insensible (comme la pression).
3. **UI** : ajouter un bouton mode « Ombrage » (à côté de Rond/Pression/Plume), câblé via `setStrokeMode`.
   Pas de nouveau slider requis (min/max dérivés de `sizeMm`) ; si un réglage s'avère utile, le placer
   dans le tiroir (S5), pas dans la barre.
4. Curseur : réutiliser le cercle (taille `sizeMm`) ; l'inclinaison variant en continu, ne pas tenter de
   dessiner un curseur variable (inutile).
5. Fallback : sans `pen`/`altitudeAngle` exploitable → trait constant (pas de crash).

### Validation
- Auto : `node test/run.js` → **vert et inchangé** (aucune géométrie nouvelle ; `variableStroke` déjà
  couvert). Smoke : un trait en mode Ombrage produit un polygone non vide.
- Humain : sur iPad + Pencil Pro — coucher le stylet élargit le trait, le redresser l'affine ; les autres
  modes inchangés ; gomme constante. → `VALIDATION.md` (P9 · S12).

### Si bloqué
Si `altitudeAngle` est trop bruité pour un trait stable (largeur qui tremble) → STOP, signale ; envisager
un lissage de l'inclinaison (EMA, comme la stabilisation T10) avant de renoncer.
