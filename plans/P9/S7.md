## T-132 — Priorité stylet, zoom-to-fit à l'entrée, indicateur de mode

### Objectif
(1) Empêcher un contact doigt de faire paner la vue **pendant** un trait Pencil en cours ; (2) cadrer la
scène sur le motif à l'entrée d'édition et restaurer la vue à la sortie ; (3) rendre le mode édition
explicite.

### Décision clé
`DECISIONS.md §D-012` pt 4-5. Priorité : dans `editPointerDown`, si un tracé `pen` est actif
(`edit.drawing` initié par un pointer pen), un `pointerdown` `touch` **ne démarre pas** de `panAnchor`
(l'idéal : l'ignorer, ou ne l'accepter que comme 2ᵉ contact d'annulation déjà géré). Cadrage :
`enterEdit` mémorise `{scale, x, y}` du stage puis anime un zoom-to-fit sur le bbox de `edit.node` ;
`exitEdit` restaure. Indicateur : liseré/bandeau « Édition : {nom} ».

### Lire / Modifier
- Modifier : `src/app.js`, `src/style.css`.

### Étapes
1. **Priorité stylet** : mémoriser le type du pointeur qui dessine (ex. `edit.drawingPointerType`, posé
   dans `startStroke`/`startShape`/`startLassoTrace`, remis à null dans les `end*`/`cancelActiveStroke`).
   Dans `editPointerDown`, branche `e.pointerType === "touch"` (l.1703-1713) : si `edit.drawing` et
   `edit.drawingPointerType === "pen"`, **ne pas** créer `edit.panAnchor` ni capturer — `return` (le
   contact touch est ignoré ; le 2ᵉ-contact-annulation existant reste possible si `activeTouchPointers.size
   > 1`). Vérifier que le rejet de paume natif n'est pas dégradé.
2. **Zoom-to-fit** : dans `enterEdit` (après verrouillage, avant/après `syncEditLayerTransform`), stocker
   `edit.prevView = { scale: stage.scaleX(), x: stage.x(), y: stage.y() }`, calculer le bbox écran de
   `edit.node` (`getClientRect`), en déduire scale/position pour le centrer avec marge (~10 %), et
   l'appliquer via une transition courte (Konva `Tween` ~200 ms, ou pose directe si le tween complique —
   noter le choix). Repositionner `editLayer` (`syncEditLayerTransform`) et la pastille après.
3. **Restauration** : dans `exitEdit`, réappliquer `edit.prevView` (tween inverse ou direct), puis
   `syncStageSize`/`positionMoveHandle` déjà présents.
4. **Indicateur de mode** : ajouter une classe `#app.editing` (posée dans `enterEdit`, retirée dans
   `exitEdit`) → CSS liseré autour de `#stage` (ex. `box-shadow: inset 0 0 0 2px #2563eb`) et/ou petit
   bandeau « ✏️ {motif.name} » ancré haut du canevas. Réutiliser `motif.name`.

### Validation
- Auto : `node test/run.js` → vert.
- Humain : sur iPad — poser un doigt pendant un trait Pencil **ne déplace plus** la vue ; entrer en
  édition recadre sur le motif, sortir restaure la vue d'avant ; le mode édition est visuellement
  évident. → `VALIDATION.md` (P9 · S7).

### Si bloqué
Si ignorer le contact touch pendant un trait pen casse le pinch-annulation (2 doigts n'annulent plus)
→ STOP, signale : la règle doit laisser passer le cas `activeTouchPointers.size > 1`.
