## T-134 — Dialogue HTML custom + badge essais en attente

### Objectif
Remplacer les `confirm()`/`alert()` natifs enchaînés — surtout les **deux confirm imbriqués** de
`guardPendingDrafts` (sémantique OK/Annuler inversée, illisible en modale iPadOS) — par un dialogue HTML
à boutons explicites ; ajouter un **badge « N essais »** dans le header.

### Décision clé
`DECISIONS.md §D-012` pt 6. `guardPendingDrafts` doit offrir 3 choix explicites : « Appliquer et
exporter » / « Exporter sans les essais » / « Annuler ». Le dialogue est **asynchrone** (Promise) — les
appelants (`exportSVG`, `exportPNG`, `collectPrintScene`) sont synchrones aujourd'hui → les adapter en
`async`/`.then` ou en callback (choisir la voie la moins invasive ; ces fonctions terminent par un
download, pas de valeur de retour consommée ailleurs).

### Lire / Modifier
- Modifier : `src/app.js`, `index.html`, `src/style.css`.

### Étapes
1. **Composant dialogue** : ajouter `#modal` (index.html, masqué) : titre + message + zone boutons
   dynamiques. Helper `showDialog({ title, message, buttons:[{label, value, kind}] })` → `Promise` qui
   résout la `value` du bouton tapé (kind `primary`/`danger`/`neutral` pour le style). Fermeture au tap
   backdrop = valeur d'annulation. Cibles ≥ `--tap`.
2. **guardPendingDrafts** : réécrire en `async` renvoyant `true`/`false` selon le choix (« Appliquer et
   exporter » → `applyAllDrafts()` puis true ; « Exporter sans » → true ; « Annuler » → false). Adapter
   `exportSVG`/`exportPNG`/`exportPdfA4`/`collectPrintScene` pour `await`/chaîner (ordre des opérations
   inchangé après la garde).
3. **Suppressions** : remplacer les `confirm(...)` de `deleteMotifFromLibrary`/`hideBuiltin` par
   `showDialog` (bouton danger « Supprimer » / neutre « Annuler »). Attention : ces fonctions retournent
   `true`/`false` de façon synchrone à des appelants (`del.onclick` qui fait `item.remove()`), à adapter
   en async (déplacer le `item.remove()` dans la résolution).
4. **alert()** : remplacer les `alert(...)` d'export/erreur par `showDialog` à un seul bouton « OK »
   (ou conserver `alert` si le coût d'async ne se justifie pas pour un simple message — prioriser les
   confirm ; noter ce qui reste en `alert`).
5. **Badge** : dans le header (`.project-history`), ajouter `#draft-badge` (masqué si 0). `refreshDraftCounter`
   met à jour le texte (`N`) et la visibilité, en plus de `#draft-summary` existant. Tap sur le badge =
   ouvrir/scroller vers la section Projet (ou déclencher Tout appliquer — au choix, noter lequel).

### Validation
- Auto : `node test/run.js` → vert.
- Humain : sur iPad — exporter avec des essais en attente ouvre le dialogue 3 choix (comportement correct
  pour chaque bouton) ; supprimer un motif avec exemplaires demande confirmation via le dialogue custom ;
  le badge « N essais » apparaît/disparaît dans le header. → `VALIDATION.md` (P9 · S9).

### Si bloqué
Si passer un appelant d'export en async casse un enchaînement non anticipé (valeur de retour consommée)
→ STOP, signale la fonction ; repli : garder `guardPendingDrafts` async pour l'export SVG/PNG/PDF et ne
convertir les suppressions que dans un second temps.
