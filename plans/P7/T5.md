## Objectif
Le tracé du mode édition (pinceau/gomme/formes/lasso) quitte les événements Konva `mouse*/touch*`
pour des **Pointer Events natifs** attachés au conteneur du stage. Comportement fonctionnel
**inchangé** pour l'utilisateur (souris et un doigt dessinent comme avant) — cette tâche est la
fondation de T6-T10 (pointerType, pression fiable, coalescés, survol).

## Décision clé
`DECISIONS.md §D-010` (volet 1) :
- Listeners **natifs** sur `stage.container()`, **attachés dans `enterEdit()`, détachés dans
  `exitEdit()`** (hors édition, rien ne change ; Konva reste maître de sélection/Transformer/pinch).
- Mapping écran→local : `stage.setPointersPositions(e)` (accepte un événement natif) **puis** le
  `localPoint()` existant (`getRelativePointerPosition`).
- `setPointerCapture(e.pointerId)` sur le conteneur au `pointerdown` ; `pointercancel` = annulation
  (jamais d'application partielle), via le `cancelActiveStroke()` de T3.
- Multi-touch : compteur de pointeurs `touch` actifs ; dès 2 → `cancelActiveStroke()` et on laisse le
  pinch Konva existant (touch events, inchangés) faire pan/zoom.
- La pression se lit désormais sur `e.pressure` (stylet), 0.5 pour souris/doigt.

## Étapes
1. Écrire trois handlers nommés `editPointerDown/Move/Up(e)` reprenant **exactement** la logique du
   dispatch actuel (l. 1452-1474) : garde `edit.active`, branchement lasso / trait libre / forme,
   `preventDefault()`. `editPointerUp` traite aussi `pointercancel` → `cancelActiveStroke()` (pas
   d'application).
2. Suivi multi-touch : `Set` des `pointerId` de type `touch` actifs (down = add, up/cancel = delete).
   Au 2ᵉ `touch` actif → `cancelActiveStroke()` puis return (le pinch Konva prend la main).
3. En tête de `editPointerDown/Move` : `stage.setPointersPositions(e);` pour que `localPoint()` lise
   la bonne position. `moveStroke`/`moveShape`/`moveLassoTrace` reçoivent l'événement **natif** —
   adapter leurs lectures (`e.evt.pressure` → `e.pressure`, `e.evt.shiftKey` → `e.shiftKey`) : soit en
   passant un objet `{ evt: e }`, soit en adaptant les fonctions ; choisir la voie qui modifie le moins
   de lignes et rester cohérent.
4. `pointerPressure(e)` : simplifier en `e.pointerType === "pen" ? Math.max(e.pressure, 0.05) : 0.5`.
5. `enterEdit()` : `container.addEventListener("pointerdown|pointermove|pointerup|pointercancel", ...,
   { passive: false })` + `setPointerCapture` au down. `exitEdit()` : `removeEventListener` symétriques
   (conserver les références des fonctions).
6. Supprimer les trois handlers Konva d'édition (l. 1452-1474) — ils ne servaient qu'au mode édition.
7. Vérifier que le pinch (l. 166-205) fonctionne toujours en édition : il est sur touch events, qui
   continuent d'être émis en parallèle des pointer events sur iOS ; ne pas le migrer.
