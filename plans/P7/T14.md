## Objectif
L'undo d'édition copie aujourd'hui **tout** le draft à chaque trait (×30 max) — sur un décor c'est un
risque mémoire réel sur Safari iPad, et il n'y a **pas de Rétablir**. Remplacer par un historique de
**commandes** (op + polygone du trait) avec **keyframes**, et ajouter redo (bouton + Ctrl+Maj+Z).

## Décision clé
`DECISIONS.md §D-010` (volet 2). Modèle :
- `edit.history` devient une liste d'entrées : `{ kind: "op", op: "add"|"sub", poly }` (trait/forme)
  ou `{ kind: "snapshot", draft }` (copie profonde — utilisée pour l'état initial, les keyframes, et
  les mutations non rejouables : lasso ×3, Jeter).
- Invariant : la première entrée de session est un snapshot (`enterEdit`) ; un snapshot (keyframe) est
  inséré automatiquement toutes les **8** entrées `op`.
- **Undo** : dépiler la dernière entrée vers `edit.redo` ; reconstruire l'état = dernier snapshot
  restant + replay des `op` postérieures (avec les fonctions *Local* de T12 → rapide).
- **Redo** : re-dépiler de `edit.redo` vers `edit.history`, rejouer l'entrée. `edit.redo` est vidé à
  chaque **nouvelle** mutation (trait, forme, lasso…).
- Borne inchangée : 30 entrées (en purgeant par l'avant, ne jamais supprimer le snapshot le plus
  ancien restant sans le remplacer par un snapshot de l'état à ce point).
- Après chaque undo/redo : recalcul plein de `edit.added` (règle T13) + `redrawEditLayer`.

## Étapes
1. Remplacer `pushStrokeSnapshot()` par `pushEditEntry(entry)` : gère le compteur d'ops depuis le
   dernier snapshot (keyframe toutes les 8 ops), la borne de 30 et le vidage de `edit.redo`.
2. Points d'appel : `applyStroke` et `endShape` poussent `{ kind: "op", op: edit.op, poly }` (le
   polygone déjà calculé du trait/de la forme) ; les trois `finalizeLasso*` et `discardMotifDraft`
   poussent `{ kind: "snapshot", draft: deepCopyContours(edit.draft) }` **avant** mutation ;
   `enterEdit` pousse le snapshot initial et vide `edit.redo`.
3. `undoStroke()` → reconstruire selon la Décision clé (fonction utilitaire
   `rebuildDraftFrom(history)` : dernier snapshot + replay des ops avec
   `surfaceUnionLocal`/`surfaceDifferenceLocal`).
4. `redoStroke()` : symétrique via `edit.redo`.
5. UI : bouton `Rétablir` à côté d'`Annuler` (l. 196-199, la `grid2` passe à 3 colonnes ou deux
   rangées — au choix le moins intrusif) ; désactivé (`disabled`) quand `edit.redo` est vide, comme
   `Annuler` quand l'historique n'a plus d'entrée annulable.
6. Clavier : dans le keydown (l. 1556), `Ctrl/Cmd+Maj+Z` → `redoStroke()` quand `edit.active`.
7. `exitEdit` : purger `edit.history` **et** `edit.redo` (déjà le cas pour history).

réintroduire de snapshot par trait.
