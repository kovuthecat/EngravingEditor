## Étapes
1. `edit.fingerDraws = false` dans l'objet `edit`.
2. Dans `editPointerDown` : si `e.pointerType === "touch"` et `!edit.fingerDraws` → ne pas démarrer de
   trait ; mémoriser `panAnchor = { x: e.clientX, y: e.clientY }` (et l'id du pointeur).
3. Dans `editPointerMove` : si un `panAnchor` est actif pour ce pointeur →
   `stage.position({ x: stage.x() + dx, y: stage.y() + dy })`, mettre à jour l'ancre,
   `stage.batchDraw()`. Le calque d'essai (`editLayer`, enfant de `uiLayer`) suit sans resync.
4. `editPointerUp`/`pointercancel` : purger `panAnchor`. Si un 2ᵉ doigt arrive (suivi T5) → purger
   `panAnchor` et laisser le pinch prendre la main.
5. `pointerType === "pen"` et `"mouse"` : dessinent (inchangé). `"touch"` avec `edit.fingerDraws` :
   dessine (ancien comportement).
6. Bouton bascule dans `#edit-palette` (après la rangée Rond/Pression/Plume) :
   `<button id="finger-draws" class="btn sm tool-btn">✍️ Doigt : navigue</button>` ; au clic, inverser
   `edit.fingerDraws`, libellé `Doigt : dessine` / `Doigt : navigue`, classe `.on` quand il dessine.
7. Mettre à jour la note l. 190 : « Pencil = trait · un doigt = déplacer la vue (sauf si “Doigt :
   dessine”) · deux doigts = zoom ».
