## Objectif
Une page HTML **autonome** (zéro dépendance, hors app) à ouvrir sur l'iPad réel pour constater ce que
Safari expose du Pencil : pression, coalescés/prédits, rotation du barillet (`twist`), inclinaison,
survol. Ses résultats conditionnent T7/T8 et le futur lot barrel roll (cf. D-010).

## Étapes
1. Créer `test/pencil-probe.html` : un `<canvas>` plein écran (`touch-action: none`) + un panneau fixe.
2. Attacher `pointerdown/pointermove/pointerup/pointercancel` sur le canvas (`{ passive: false }`,
   `preventDefault()`), tracer une ligne brute par événement (fillRect ou lineTo simple) pour ressentir
   la latence.
3. Panneau « live » (mis à jour à chaque événement) : `pointerType`, `pressure` (et min/max vus),
   `tiltX/tiltY`, `twist`, `altitudeAngle`/`azimuthAngle` (afficher `absent` si `undefined`),
   `getCoalescedEvents().length` et `getPredictedEvents().length` (0 / `absent` si API manquante),
   nombre de pointeurs actifs.
4. Panneau « bilan » (booléens qui passent au vert dès qu'observés une fois) :
   `pen détecté` · `pressure variable (≠ 0.5)` · `coalesced > 1` · `predicted ≥ 1` ·
   `twist ≠ 0 observé` · `tilt/altitude présents` · `survol observé` (pointermove avec `buttons === 0`
   et `pointerType === "pen"`).
5. Bouton « Copier le bilan » : copie un résumé texte dans le presse-papier
   (`navigator.clipboard.writeText`, fallback : afficher le texte à sélectionner).
