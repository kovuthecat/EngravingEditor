## Objectif

Fonction pure `ML.computeTiling(bbox, opts)` qui découpe un bbox en mm en grille de feuilles A4
avec recouvrement, en choisissant l'orientation qui minimise le nombre de feuilles.

## Décision clé

`DECISIONS.md §D-011 (point 3 et 5)`. Constantes par défaut : page 210×297 mm, marge imprimante
10 mm, recouvrement 10 mm. Fenêtre utile = page − 2×marge. Pas de grille = fenêtre − recouvrement.

## Étapes

1. Signature : `ML.computeTiling(bbox, opts)` avec `bbox = {x, y, w, h}` (mm, repère scène sens
   écran) et `opts = {pageW:210, pageH:297, margin:10, overlap:10}` (tous optionnels, défauts
   ci-dessus).
2. Pour chaque orientation (portrait `210×297`, paysage `297×210`) :
   - `uw = pageW − 2·margin`, `uh = pageH − 2·margin` (fenêtre utile) ;
   - `stepX = uw − overlap`, `stepY = uh − overlap` ;
   - `cols = max(1, ceil((w − overlap) / stepX))`, idem `rows` avec `h`/`stepY`
     (cas `w ≤ uw` → 1 colonne ; garde : si `w − overlap ≤ 0` → 1).
3. Retenir l'orientation au **nombre de feuilles minimal** (`cols×rows`) ; égalité → portrait.
4. Centrer la grille sur le bbox : couverture `covW = cols·stepX + overlap` ;
   `originX = bbox.x − (covW − w)/2` ; idem Y.
5. Retour :
   `{ landscape, cols, rows, pageW, pageH, margin, overlap, uw, uh,
      pages: [{ row, col, x, y, label }] }`
   où `x, y` = coin haut-gauche de la **fenêtre utile** en coordonnées scène
   (`x = originX + col·stepX`), `label = "L{row+1}·C{col+1}"`, pages ordonnées ligne par ligne.
6. Cas de test dans `test/run.js` (voir Validation), lancer `node test/run.js`.
