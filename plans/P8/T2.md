## Objectif

Vendorer jsPDF (UMD) et créer `src/print.js` (classic script) : `ML.renderPrintPdf(scene, tiling,
opts)` dessine une feuille A4 par page de `tiling` (clip fenêtre utile, surfaces gris clair
`evenodd`, contours couleur calque 0,3 mm, contour guitare pointillé) et retourne le doc jsPDF.

## Étapes

1. Vendorer jsPDF : build UMD minifiée officielle (dist `jspdf.umd.min.js`, version 2.x). Vérifier
   qu'en classic script elle expose `window.jspdf.jsPDF`.
2. `src/print.js` : IIFE attachée à `window.ML` (même style que `geometry.js`).
   Contrats d'entrée :
   - `scene = { surfaces: {color: [{pts}]}, boundary: [[x,y],...]|null, holes: [[[x,y],...]]|null,
     bbox: {x,y,w,h} }` — tout en mm sens écran (fourni par T4) ;
   - `tiling` = retour de `ML.computeTiling` (T1) ;
   - `opts = { strokeMm:0.3, fillGray:230, dashMm:[3,2], boundaryGray:136 }` (défauts).
3. `ML.renderPrintPdf(scene, tiling, opts)` :
   - `const doc = new jspdf.jsPDF({ unit:"mm", format:"a4", orientation: tiling.landscape ?
     "landscape" : "portrait" })` ; la 1ʳᵉ page existe déjà, `addPage()` pour les suivantes.
   - Par page `p` : transformation scène→page `tx(x) = x − p.x + margin`, `ty(y) = y − p.y + margin`.
   - **Clip fenêtre utile** : `doc.saveGraphicsState(); doc.rect(margin, margin, uw, uh, null);
     doc.clip(); doc.discardPath();` … dessin … `doc.restoreGraphicsState();` (si l'API de la
     version vendored diffère — `clip_fixed`, absence de `discardPath` — adapter à sa doc, c'est le
     seul point d'API incertain).
   - **Pré-filtrage** : ne dessiner que les sous-chemins dont le bbox intersecte la fenêtre
     `[p.x − strokeMm, p.x + uw + strokeMm] × [p.y − …, …]` (gros décor × N pages : jamais de
     Clipper ici, le clip PDF fait la découpe visuelle).
   - **Surfaces** : pour chaque couleur, construire UN chemin multi-sous-chemins via
     `doc.path([{op:"m",c:[x,y]}, {op:"l",c:[x,y]}…, {op:"h"}, …])` puis
     `doc.setFillColor(g,g,g)` (gris `fillGray`) et `doc.fillEvenOdd()` — un seul `path` par
     couleur et par page, sinon les trous `evenodd` sont perdus.
   - **Contours** : mêmes sous-chemins, `doc.setDrawColor(couleur du calque)`,
     `doc.setLineWidth(strokeMm)`, `doc.stroke()` (chemin fermé via `{op:"h"}`).
   - **Contour guitare + cavités** (`scene.boundary`, `scene.holes`) :
     `doc.setLineDashPattern(dashMm, 0)`, gris `boundaryGray`, largeur 0,2 mm, stroke, puis
     `doc.setLineDashPattern([], 0)` (reset).
4. Smoke local : ouvrir la console du navigateur n'est pas requis pour cette tâche (pas de bouton
   encore) — vérifier au minimum que `index.html` charge sans erreur console nouvelle
   (`python -m http.server` ou `file://`) et que `window.ML.renderPrintPdf` et `window.jspdf`
   existent.
