## Étapes

1. `collectPrintScene()` dans `app.js` :
   - garde `guardPendingDrafts()` puis `instancesBottomToTop()` ; vide → `alert("Rien à
     imprimer.")` + retour `null` (mêmes messages/logique que `exportPNG`) ;
   - `visible = ML.occludeSurfaces(insts, state.boundary, reservedPolys())` ;
   - conversion mm sens écran : chaque point `[x, y] → [x / PX_PER_MM, y / PX_PER_MM]` appliquée
     aux surfaces par couleur, à `state.boundary` et `state.holes` ;
   - bbox : sur tous les points visibles + le contour s'il existe (même logique que `exportPNG`) ;
     rien de visible → alert + `null` ;
   - retour `{ surfaces, boundary, holes, bbox }` (contrat T2).
2. `exportPdfA4()` : `scene = collectPrintScene()` ; si `null` retour ;
   `tiling = ML.computeTiling(scene.bbox)` ; `doc = ML.renderPrintPdf(scene, tiling)` ;
   `doc.save("pattern-A4.pdf")`.
3. `index.html` : bouton `id="export-pdf"`, libellé « PDF A4 1:1 », même style/emplacement que les
   boutons d'export existants ; câblage dans `app.js` au même endroit que les autres.
4. Vérifier le chargement sans erreur console et le clic (téléchargement d'un PDF) dans un
   navigateur local si disponible ; sinon laisser à la validation humaine.
