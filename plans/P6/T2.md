## Objectif
Permettre d'importer un **PNG** (dessin Procreate) comme décor : l'app le **vectorise en interne**
(ImageTracer.js vendored) en chemins SVG mono-couleur, puis réutilise le pipeline décor existant.

## Décision clé
`DECISIONS.md §D-009`. Vectorisation **in-app**, lib **vendored** (pas de build, `file://` doit marcher).
Seuillage sur **l'alpha** (encre = pixel dont `alpha > SEUIL`) pour capter le trait quel que soit sa
couleur → sortie **bilevel** → une seule couleur focale décor. Le PNG est décodé par le navigateur
(`drawImage`), donc le bug « chunk C2PA » (cf. mémoire) ne s'applique pas ici.

## Étapes
1. Placer `vendor/imagetracer.js` et l'ajouter en `<script>` avant `app.js`.
2. Helper `pngFileToParsedSVG(file, cb)` dans `app.js` :
   a. `URL.createObjectURL(file)` → `new Image()` ; `img.onload` :
   b. dessiner sur un `<canvas>` hors écran à la taille naturelle, **plafonnée** (dim. max ~2000 px,
      mise à l'échelle proportionnelle) pour borner le coût de tracé ;
   c. `getImageData` → parcourir les pixels : `alpha > 128` ⇒ noir opaque `(0,0,0,255)`, sinon
      transparent `(0,0,0,0)` (seuillage bilevel) ;
   d. `ImageTracer.imagedataToSVG(imagedata, options)` avec une palette 2 couleurs
      (`pal:[{r:0,g:0,b:0,a:255},{r:255,g:255,b:255,a:0}]`) et `pathomit`/`ltres`/`qtres` par défaut ;
   e. `const parsed = ML.parseSVG(svgString)` ; ne garder que le(s) `paths` de couleur **sombre**
      (ignorer un éventuel groupe transparent/blanc) ; `URL.revokeObjectURL` ; `cb(parsed)`.
   f. En cas d'erreur (image illisible, tracé vide) → `alert` explicite et ne pas planter.
3. UI import : dans la section Décor de `index.html`, ajouter à côté de l'import SVG
   `<label class="btn">Importer décor (PNG)…<input id="import-decor-png" type="file" accept="image/png,image/jpeg" hidden /></label>`.
4. Câblage `app.js` (près de `import-decor`, l.1894) : `import-decor-png` `.onchange` →
   afficher l'overlay busy (`#busy-overlay`), `pngFileToParsedSVG(file, (parsed) => { ... })` ; dans le
   callback : `recordHistory()`, `addMotifToLibrary(buildMotifFromSVG(base, parsed, "DECOR"))`,
   `markProjectChanged()`, masquer l'overlay. (Ne pas utiliser `runWithBusy` tel quel : la vectorisation
   est **asynchrone**, l'overlay doit rester jusqu'au callback.) Réinitialiser `e.target.value = ""`.
