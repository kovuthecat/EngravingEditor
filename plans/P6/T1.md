## Objectif
Ajouter une bascule **globale** qui, quand elle est active, rend **tous les exemplaires de décor**
(motifs de rôle `DECOR`) inertes : plus sélectionnables, plus déplaçables, plus éditables. Les motifs
posés au-dessus restent sélectionnables (le clic traverse le décor verrouillé).

## Décision clé
`DECISIONS.md §D-009`. Levier = `node.listening(false)` sur les groupes décor (inerte au pointeur,
le clic passe au travers). État **global** `state.decorLocked` (pas par exemplaire), **persisté** dans
le JSON projet. Verrou visuel uniquement, **aucun effet sur l'export** (géométrie inchangée).

## Étapes
1. `state` : ajouter `decorLocked: false`.
2. Helper `isDecorGroup(node)` : `node?.getClassName()==="Group"` et le motif de `node.getAttr("motifId")`
   a `role==="DECOR"` (via `state.motifs.find`).
3. Fonction `applyDecorLock()` : pour chaque groupe de `mainLayer` tel que `isDecorGroup`, faire
   `g.listening(!state.decorLocked)`. Si on **verrouille** : si `isDecorGroup(selected())` → `select(null)` ;
   si `edit.active` et le motif édité est un décor → `exitEdit()`. Terminer par `mainLayer.batchDraw()`.
4. `makeGroup()` : juste avant `return g`, si `motif.role==="DECOR" && state.decorLocked` → `g.listening(false)`
   (couvre addInstance, duplication, chargement).
5. Garde dans `select()` : tout en haut, `if (state.decorLocked && isDecorGroup(node)) return;`.
6. Garde dans `enterEdit()` : si le motif courant est un décor et `state.decorLocked` → `return`.
7. Bouton UI : dans la section Décor de `index.html`, ajouter
   `<button id="btn-lock-decor" class="btn sm" type="button" aria-pressed="false">🔓 Décor déverrouillé</button>`.
   Câbler dans `app.js` (près des autres `getElementById(...).onclick`) : bascule `state.decorLocked`,
   met à jour le libellé (`🔒 Décor verrouillé` / `🔓 Décor déverrouillé`) et `aria-pressed`, appelle
   `applyDecorLock()` puis `markProjectChanged()`.
8. Persistance : dans `projectData()` ajouter `decorLocked: state.decorLocked`. Dans `loadProject()`,
   après la boucle des instances (l.1737), faire `state.decorLocked = !!data.decorLocked`, resynchroniser
   le libellé/`aria-pressed` du bouton, puis `applyDecorLock()`.
9. (Style facultatif) `.btn.sm[aria-pressed="true"]` : fond distinct pour signaler l'état verrouillé.
