## Objectif
Bouton **« Rafraîchir le décor… »** : re-sélectionner un PNG (dessin retravaillé sur Procreate) et
**remplacer la géométrie du décor existant sur place** — mêmes exemplaires, mêmes position / échelle /
rotation / z-order (la transformation vit sur l'exemplaire, pas sur la géométrie).

## Décision clé
`DECISIONS.md §D-009`. Re-sélection du fichier à **chaque** rafraîchissement (universel iPad+desktop ;
pas de mémorisation de chemin — impossible en navigateur iPad). Remplacement = **muter le motif décor
existant** (`motif.id` conservé) : `zones`/`silhouette` remplacés, `motif.surface` **supprimé** (les
retouches stylet du décor sont écrasées, attendu), puis `rerenderMotif(motif)`. Le motif est recentré
sur son bbox → l'alignement reste stable **si le cadrage du canvas Procreate est constant** (à noter dans
le message/`VALIDATION.md`).

## Étapes
1. UI : dans la section Décor de `index.html`, ajouter
   `<button id="btn-refresh-decor" class="btn sm" type="button">Rafraîchir le décor…</button>` +
   `<input id="refresh-decor-file" type="file" accept="image/png,image/jpeg" hidden />`.
2. Câblage : clic sur `#btn-refresh-decor` → choisir le décor cible **avant** d'ouvrir le sélecteur :
   - cible = motif du décor **sélectionné** si `selectedMotif()?.role==="DECOR"` ; sinon, s'il n'existe
     **qu'un seul** motif de rôle `DECOR` dans `state.motifs`, le prendre ; sinon `alert`
     (« Sélectionne d'abord le décor à rafraîchir. ») et stop.
   - mémoriser cette cible, puis `refreshDecorFile.click()`.
3. `#refresh-decor-file` `.onchange` → `refreshDecor(file)` avec la cible mémorisée ; `e.target.value=""`.
4. `refreshDecor(target, file)` :
   a. overlay busy ON ; `recordHistory()` ;
   b. `pngFileToParsedSVG(file, (parsed) => { ... })` ;
   c. dans le callback : construire une géométrie fraîche `const fresh = buildMotifFromSVG(target.name, parsed, "DECOR")` ;
      muter la cible : `target.zones = fresh.zones; target.silhouette = fresh.silhouette; delete target.surface;`
      (conserver `id`, `name`, `role`, `color`, `margin`) ;
      `rerenderMotif(target)` (re-rend tous les exemplaires + les vignettes) ; rafraîchir la vignette
      bibliothèque si `rerenderMotif` ne le fait pas déjà (`drawThumb(motifThumbs[target.id], target)`) ;
      `markProjectChanged()` ; overlay OFF.
   d. erreur/tracé vide → message propre, overlay OFF, pas de mutation.
5. Si la cible était un **built-in** promu, `rerenderMotif` gère déjà — ne rien ajouter de spécial.
