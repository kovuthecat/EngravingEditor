## T-142 — Tokens de design + typographie vendored

### Objectif
Poser le **socle visuel** de la nouvelle UI : variables CSS (couleurs oklch, rayons, espacements,
`--tap`, ombres) reprises de la maquette, et **polices IBM Plex vendored hors-ligne** (l'app tourne en
`file://`, pas de CDN).

### Décision clé (D-013 pt 5, 6)
- Polices **vendored** dans `vendor/fonts/` + `@font-face` locaux (pas de `fonts.googleapis.com`).
- Palette **oklch** adoptée telle quelle en tokens `:root`.

### Lire / Modifier
- Modifier : `src/style.css`, `index.html` (head : retirer tout `<link>` Google Fonts s'il en apparaît,
  ne rien ajouter vers un CDN), ajouter `vendor/fonts/` (fichiers `.woff2` + un `fonts.css` local si tu
  sépares, sinon `@font-face` dans `style.css`).

### Étapes
1. **Polices** : récupérer IBM Plex Sans (400/500/600/700) et IBM Plex Mono (400/500/600) en `.woff2`,
   les déposer dans `vendor/fonts/`, déclarer les `@font-face` (chemins **relatifs**, pour `file://`).
   Familles : corps = `'IBM Plex Sans', system-ui, sans-serif` ; monospace (dimensions/labels) =
   `'IBM Plex Mono', ui-monospace, monospace`.
   - Si l'obtention des `.woff2` n'est pas possible dans cette session → **STOP**, signaler ; repli
     provisoire = pile système (`system-ui`) en gardant les tokens (D-013 pt 5 fallback).
2. **Tokens `:root`** (nommer d'après l'usage, valeurs de la maquette l.433-460 + l.19-27) :
   - Fonds : `--bg: oklch(0.965 0.008 75)` (app), `--surface: oklch(0.995 0.004 75)` (barres/panneaux),
     `--canvas: oklch(0.93 0.01 75)` ; `--line: oklch(0.84 0.012 65)` (bordures/séparateurs).
   - Encre : `--ink: oklch(0.19 0.02 55)` ; `--muted: oklch(0.46 0.02 60)`.
   - Accents : `--accent: oklch(0.66 0.17 45)` ; `--green: oklch(0.62 0.14 150)` ;
     `--blue: oklch(0.53 0.1 240)` ; `--red: oklch(0.58 0.19 25)` ; `--zone-red: oklch(0.6 0.19 25)`.
   - Palette gravure (6) `--pal-1..6` = valeurs `PALETTE` l.453-460.
   - Rayons : `--r-sm:8px --r-md:10px --r-lg:12px --r-xl:14px --r-pill:999px`.
   - Cible tactile : `--tap:44px` (réutiliser si déjà défini par P9·S1 — **ne pas dupliquer**).
   - Ombres : `--shadow-pop: 0 8px 24px rgba(0,0,0,0.2)` (barres flottantes),
     `--shadow-card: 0 4px 14px rgba(0,0,0,0.1)`.
3. **Range** : reporter le style de slider de la maquette (l.17-20) via les tokens (piste 6px
   `--line`, pouce 30px `--accent` bord blanc). Fusionner avec la règle sliders existante de P9·S1
   (ne pas la casser ; garder la piste de hit 44px).
4. **Base** : `body { background: var(--bg); color: var(--ink); font-family: … }`. Ne pas encore
   restructurer le layout — juste que l'app reste affichable.
5. Vérifier qu'en desktop **et** en `file://` (double-clic `index.html`) les polices se chargent depuis
   `vendor/fonts/` (onglet réseau : aucune requête externe).
