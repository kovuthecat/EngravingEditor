## T-146 — Panneau Export + zoom + aides canevas

### Objectif
Recréer le **panneau Export & sauvegarde** et ajouter les **incrustations canevas** : contrôles de zoom
flottants, pastille d'aide, toast. Finaliser le câblage du bouton **Exporter** de la barre supérieure (S2).

### Décision clé
Zoom : la maquette ajoute des **boutons +/reset/−** explicites (l.378-383) en plus de la molette/pinch
existants. On ajoute les boutons, on **conserve** molette + pinch (aucune fonction retirée). Le zoom pilote
la même transformation de stage que l'existant.

### Lire / Modifier
- Modifier : `index.html` (panneau Export + zoom + pastille + toast), `src/style.css`, `src/app.js`.

### Étapes
1. **Panneau Export** (`.dc.html` l.293-321) rendu si `activePanel==='export'` :
   - **DPI (PNG/JPEG)** : select 150/300/600 (ou garder l'input number existant `export-dpi` habillé —
     conserver la plage réelle 50-1200 si le number est gardé ; ne pas réduire la fonction).
   - Grille 2×2 : **Exporter SVG**, **Exporter PNG**, **Exporter JPEG**, **PDF A4 1:1** → boutons existants.
   - Note « SVG = miroir vertical (gravure) · PNG/JPEG = sens écran ».
   - Séparateur, puis **Enregistrer sur cet iPad** (accent), **Charger**, **Tout effacer** (rouge) →
     `btn-save`/`load-project`/`btn-clear`. Le bloc « essais en attente » (`draft-summary` + tout appliquer)
     est déjà porté par la bannière S2 ; ne pas le dupliquer ici (ou le garder discret si `app.js` l'exige).
   - Le bouton **Exporter** de la barre supérieure (S2) ouvre ce panneau (`openExport`) — finaliser.
2. **Zoom flottant** (`.dc.html` l.378-383) : pile verticale bas-droite (+ / label % / −), fond
   `--surface`, ombre `--shadow-card`, respect `safe-area-inset-bottom`. Câbler `zoomIn`/`zoomReset`/
   `zoomOut` sur la même mécanique que la molette existante (facteur cohérent, bornes identiques). Le
   label affiche le zoom courant (`Math.round(zoom*100)+'%'`).
3. **Pastille d'aide** (`.dc.html` l.326-333) : bandeau `pointer-events:none` haut-centre du canevas
   « Glisser un motif pour le déplacer · appuyer pour le sélectionner ». Remplace le `.hint` desktop
   verbeux ; masquer sous desktop souris si redondant (cf. `(pointer:coarse)` de P9·S1). Texte concis.
4. **Toast** (`.dc.html` l.413-416) : incrustation haut-centre, fond `--ink`, auto-masquée ~2.6s. Brancher
   sur le mécanisme de notification existant s'il y en a un (`showToast`/`local-save-status`) ; sinon
   ajouter un helper minimal réutilisé par imports/exports/erreurs (ne pas remplacer les dialogues
   custom de confirmation — juste les notifications non bloquantes).

  `btn-export(-png/-jpeg)`, `export-pdf`, `btn-save`, `load-project`, `btn-clear`, `draft-summary`/
  `draft-count-label`/`btn-draft-apply-all` — requis par `refreshDraftCounter`, gardés discrets en

  orpheline) a été retirée d'`app.js` ; `openExportMinimal` remplacé par `openExport()` (même schéma
  que `openSelectionPanel` de S4 — ouverture forcée, pas un toggle) branché sur `btn-export-open` ;
  `rail-export` bascule maintenant en toggle standard (`setPanel("export")`) comme les autres rails.

  tels quels (hors périmètre, cf. décision déjà actée en P9·S9).

  retiré lors d'une session antérieure) ; masquée en `@media (hover:hover) and (pointer:fine)`
