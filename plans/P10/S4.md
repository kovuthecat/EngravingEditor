## T-145 — Panneau Sélection + barre sombre contextuelle

### Objectif
Recréer le **panneau Sélection** (réglages du motif sélectionné) et la **barre contextuelle sombre**
flottante (actions rapides centrées bas), en remplacement de `#inspector` + `#selection-palette`.

### Décision clé (D-013 pt 3, 7)
- **Couleur** : garder **uniquement** le sélecteur natif `<input type=color>` (`insp-color`, handler
  inchangé). Les 6 pastilles de la maquette **ne sont pas reprises** (tranché par Thibault le 2026-07-07).
- **Barre de sélection** = barre **sombre flottante centrée-bas** (remplace `#selection-palette` positionné).
- Le **rôle** (Personnage/Symbole/Décor, `insp-role`) existant est **conservé** dans le panneau.

### Lire / Modifier
- Modifier : `index.html` (panneau Sélection + barre sombre), `src/style.css`, `src/app.js` (rebranchement).

### Étapes
1. **Panneau Sélection** (`.dc.html` l.244-291) rendu dans le shell quand `activePanel==='selection'` :
   - **Si sélection** :
     - Bouton **« ✎ Entrer en édition (zones REMPLI/VIDE) »** (sombre, pleine largeur) → `btn-edit`/`enterEdit`.
     - **Dupliquer / Supprimer** (Supprimer en rouge).
     - **Couleur de gravure** : les 6 pastilles (grille 3×2) **+** le `<input type=color>` conservé
       (préréglage rapide OU teinte libre) → tous deux écrivent `motif.color` via le handler existant.
     - **Rôle** (`insp-role`) : select conservé.
     - **Marge du motif (mm)** : slider (`insp-margin`, 0-6 step 0.5) + label mono.
     - **Ordre (z)** : « ⏫ Tout devant » / « ⏬ Tout derrière » (`btn-front`/`btn-back`).
     - **Position fine** : Rotation (slider -180..180, `insp-rot`) + Échelle (slider 0.3..2.5, `insp-scale`).
       Ces sliders remplacent les number inputs, **même handler** (mettre à jour le motif Konva en direct).
   - **Si pas de sélection** : message centré « Appuyez sur un motif du canevas pour afficher ses réglages ici. »
2. **Barre contextuelle sombre** (`.dc.html` l.385-395) : incrustation `position:absolute` centrée bas du
   canevas, fond `--ink`, rayon 16, ombre `--shadow-pop`. Boutons : **⧉ Dupliquer**, **▼ Descendre**,
   **▲ Monter**, séparateur, **✎ Modifier** (accent → ouvre panneau Sélection / `openSelection`),
   **Supprimer** (rouge clair). Visible **si sélection ET pas en mode édition** (`selected && !motifEditId`).
   Rebrancher sur `duplicateSelected`/`sendToBack`/`bringToFront`/`deleteSelected` existants.
   → Cette barre **remplace** `#selection-palette` : retirer l'ancien nœud une fois recâblé (vérifier que
   `app.js` ne le référence plus, ex. `document.getElementById("selection-palette").hidden = …` l.829/1066
   → adapter vers le nouvel élément).
3. **Cohérence rendu** : la valeur des sliders/pastilles doit **refléter** le motif courant (et un
   éventuel essai en attente `pendingEdits`, comme la maquette l.1179-1189 le fait pour couleur/marge).
   Réutiliser la logique de synchronisation d'inspecteur déjà présente (`insp-color.value = motif.color`,
   etc.).
