## T-144 — Rail d'icônes + shell de panneaux + 3 panneaux

### Objectif
Remplacer la sidebar unique par le **rail d'icônes** (78 px, 5 entrées) + un **panneau coulissant**
(336 px) piloté par `activePanel` (un seul ouvert, re-clic = ferme). Remplir les panneaux **Motifs &
décor**, **Contour**, **Guides**.

### Décision clé (D-013 pt 2)
Zéro fonction perdue. Les cases « activer marge de sécurité » / « activer cadre laser » de la sidebar
actuelle sont **conservées** (la maquette n'affiche que les sliders : garder un toggle discret, ou
convention marge=0 ⇒ masquée — voir étape 4). Le lock décor, restore builtins, refresh décor : conservés.

### Lire / Modifier
- Modifier : `index.html` (rail + shell + 3 panneaux), `src/style.css`, `src/app.js` (routing panneaux +
  rebranchement).

### Étapes
1. **Rail** (`.dc.html` l.67-107) : colonne 78 px, fond `--surface`, bord droit `--line`. 5 boutons

   **Export** (bas). État actif = fond/bordure/encre accent (helpers `railBg/railFg/railBorder` de la
   maquette l.1121 ; réimplémenter simplement en togglant une classe `.active`). Chaque bouton →
   `openLibrary/openContour/openGuides/openSelection/openExport`.

3. **Panneau Motifs & décor** (`.dc.html` l.113-162) : déménager le contenu de `#lib-section`.
   - Onglets **Personnages / Symboles** (segmented control, `libraryTab`) → basculer les deux grilles
     existantes `#library-perso` / `#library-symbole` (garder les grilles et leurs vignettes Konva/lazy
     existantes ; ne remplacer que l'habillage onglets + compteurs).

   - « Restaurer la bibliothèque de base » conservé.
   - Bloc **Décor** : aperçu + Importer décor + Rafraîchir (↻) + **verrou décor** (bouton cadenas,
     libellé « Décor verrouillé/déverrouillé ») → tous rebranchés sur les handlers actuels. Conserver
     les deux imports décor (SVG **et** PNG) — la maquette n'en montre qu'un ; garder les deux (accept
     `.svg,.png`).
4. **Panneau Contour** (`.dc.html` l.164-184) : aperçu contour, **Dim. longue / Dim. courte (mm)**
   (inputs number, `inputmode="decimal"`), bouton « Charger un contour SVG — recommandé », note. Rebrancher
   `dim-long`/`dim-short`/`import-svg`.
5. **Panneau Guides** (`.dc.html` l.186-242) : regrouper **Marge de sécurité** (slider + label mm),
   **Cadre laser** (W/H number + rotation slider), **Zone interdite** (bouton +), **Rangement assisté**

     à côté du titre de section (« Marge de sécurité ⬤ », « Cadre laser ⬤ »). Ne pas les supprimer.
6. **Nettoyage** : retirer l'ancien `<aside id="sidebar">`/`<details>` une fois le contenu déplacé.
   **Vérifier** chaque `getElementById`/`querySelector` de `app.js` : tout id réutilisé doit exister dans
   le nouveau DOM (ids inchangés de préférence → recâblage minimal). Aucun handler perdu.
